LINUX and GIT quick reference cheat sheet

LINUX

<strong>pwd</strong> shows what directory you are currently in

<strong>mkdir</strong>  make a new directory

<strong>cd</strong>  change directory (ie: cd ~/music)

<strong>ls</strong>  show contents of a directory

<strong>vi</strong>  text editor in Linux.  'i' to edit 'o' to add new line and open editor ':wq' to write and quit
