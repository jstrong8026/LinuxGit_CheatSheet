<h1>LINUX and GIT quick reference cheat sheet</h1>

<h2>LINUX</h2>

<ul>
<li><strong>pwd</strong> shows what directory you are currently in </li>

<li><strong>mkdir</strong>  make a new directory</li>

<li><strong>cd</strong>  change directory (ie: cd ~/music)</li>

<li><strong>ls</strong>  show contents of a directory</li>

<li><strong>vi</strong>  text editor in Linux.  'i' to edit 'o' to add new line and open editor ':wq' to write and quit</li>

<li><strong>mv file1 file2</strong>  rename a file by 'moving' it to the same directory with a new name</li>

<li><strong>more filename</strong>  views contents of a text file until it fills the active terminal window. Spacebar advances one full screen, q quits</li>

</ul>

<h2>GIT</h2>

<ul>
<li><strong>git init</strong>  initializes a directory for the first time to use git </li>

</ul>
